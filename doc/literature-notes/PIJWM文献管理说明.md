# PI-JWM 本地文献管理说明

> **2026-10-16 更新**：本文件描述的本地库已退役。PI-JWM 文献现行唯一入口为 Zotero 集合 `PKU → PIJWM`（七个主题子集合 + 原 CSV 分类/角色/证据/主题标签）。以下内容保留为迁移前的历史记录。

## 1. 权威入口

- `文档/文献/`是PI-JWM唯一的现行文献库，Zotero不再作为PIJWM维护入口。
- `文献索引.csv`保存逐项元数据、分类、本地路径、来源和SHA-256。
- `文献索引.md`提供总体数量与分类概览。
- `需要手动下载.md`只列尚无本地PDF的条目。
- `PDF_SHA256SUMS.txt`用于检查PDF是否缺失、重复或发生字节变化。
- `本地文献库状态.json`保存当前机器可读统计和版本边界。

## 2. 分类目录

每篇PDF只放入一个主要分类目录：

1. `01_系统场景与问题定义`
2. `02_严格双图与图学习`
3. `03_世界模型与状态预测`
4. `04_任务卸载与资源优化`
5. `05_数据集、测量与仿真`
6. `06_评价、不确定性与决策诊断`
7. `99_综述与奠基性文献`

一篇论文可以具有多个研究主题，但不得为此复制PDF。交叉分类统一写入`文献索引.csv`的`AllCategories`和`Tags`字段。

## 3. 收录标准

默认收录近三年正式发表、且能直接支撑PI-JWM系统建模、严格双图、世界模型、任务与资源演化、数据或评价的论文。下列内容允许破格保留：

- 奠基性工作或标准方法定义；
- 至今没有更合适替代工作的代表性论文；
- 对PI-JWM有直接启发、但仍需明确标注为预印本的最新工作；
- 历史研究中已经形成可追溯证据链的本地参考论文。

AirFogSim论文归入“数据集、测量与仿真”，不能把仿真器文献写成PI-JWM框架证据。`D:\shen\PKU\RRM`是独立项目，其文献不得静默并入本库。

## 4. 新文献加入流程

1. 依次使用DOI、arXiv ID、规范化题名加作者/年份检查`文献索引.csv`。
2. 核实论文版本、发表状态、DOI和来源，不以搜索摘要代替原始页面或正文。
3. 优先获取合法开放版本；无法自动获得时写入`需要手动下载.md`。
4. 检查文件头为`%PDF-`，确认首页题名与目标条目一致。
5. 选择唯一主要分类目录；多主题关系只写索引，不复制文件。
6. 计算SHA-256并与`PDF_SHA256SUMS.txt`去重。
7. 更新`文献索引.csv`、`文献索引.md`、`PDF_SHA256SUMS.txt`、`本地文献库状态.json`，再从缺失清单移除该条目。

## 5. 去重和文件命名

- DOI相同首先视为同一文献候选；合并前仍要核对预印本与正式版本差异。
- DOI缺失时使用arXiv ID，其次使用规范化题名、作者和年份。
- 元数据相同但SHA-256不同的文件可能是不同版本，不能直接删除；保留一个主阅读版本并在索引中记录差异。
- SHA-256相同的PDF只保留一份。
- 文件名优先使用`第一作者_年份_短题名.pdf`；历史文件名可保留，但必须由索引提供稳定定位。

## 6. 历史来源与本地维护

- 一次性外部文献库导出、附件清单和迁移过程文件已在本地库验收后清理，不是现行维护入口。
- `文献索引.csv`中的历史来源键只用于追溯，不代表外部附件仍存在，也不能用于定位本地PDF。
- 以后新增论文直接维护本地PDF、CSV索引和SHA-256清单，不再生成外部文献库快照。
- 若本地只有预印本而元数据对应正式出版物，必须在`Source`或标签中写明版本，不能把预印本表述为出版社PDF。

## 7. 删除边界

- 不直接修改`zotero.sqlite`。
- 本地PDF删除前必须核对索引、引用、SHA-256和替代文件；没有单独授权时只报告重复或失效候选。
- 任何清理都不得影响独立的RRM、DRIFT、导师或其他项目资料。

# PI-JWM系统指标增强与残差GPU训练实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不访问locked-test的前提下，先完成残差严格双图GPU比较和完整系统指标汇总，再从现有正式轨迹构造端到端时延、应用层吞吐量、UAV能耗与公平性真实标签。

**Architecture:** 阶段A在现有正式张量和模型接口上增加末值残差输出、系统重点损失和扩展比较表，形成绝对值/残差×独立/耦合的2×2受控比较。阶段B以独立sidecar保存系统结果标签，通过逐轨迹一步滚动评价重建完成事件和系统统计，不改变物理图、信息图或DAG定义。

**Tech Stack:** Python 3.10、PyTorch、NumPy、标准库`unittest`、AirFogSim正式冻结产物、RTX 4090。

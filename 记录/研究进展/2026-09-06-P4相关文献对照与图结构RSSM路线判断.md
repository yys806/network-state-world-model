# P4 相关文献对照与图结构 RSSM 路线判断

日期：2026-09-06
状态：文献与现有代码只读对照完成；未实现新方法，未训练，未访问 `locked_test`。

## 结论

已有文献没有支持继续围绕当前全局 RSSM correction 调权重。最直接的共同经验是：多对象或网络系统应让随机/循环状态与实体对齐，再用图消息建模实体间作用；物理运动应由速度、方向、动作和可验证更新机制支撑；联合表征与动力学通常分阶段训练；多任务冲突应先测梯度，再决定平衡或拆分。

当前 `FormalCompleteRSSMWorldModel` 已闭合 prior/posterior、KL、teacher 和 prior-only rollout 语义，但它把全部节点、边、流、任务和动作池化为一个全局 RSSM 状态，再将同一个 correction 广播到所有同类实体。它应准确称为“全局 aggregate RSSM adapter over formal dual-graph base”，不能再把其空间结构描述成“每个节点/链路都有随机图状态的 Graph-RSSM”。

## 现有代码与文献方法的关键差异

正式实现 `code/src/pi_jwm/formal_complete_rssm_world_model_v1.py` 中：

1. `_state_summary()` 对每类实体做 masked pool，再拼成一个全局向量；
2. `_action_summary()` 对所有任务动作做 masked pool；
3. 全模型只有一个 `rssm_transition`、一个 prior 和一个 posterior；
4. 状态 correction 在 decoder 后 `unsqueeze(-2)`，加到同类所有实体；
5. link correction 同样只产生每个 sample/step 一个标量，再广播到所有边。

由此可直接推出：

- 同一 sample、同一步中，RSSM 给所有物理节点相同的 node-x correction，只能整体平移，不能分别修正车辆/UAV 的不同运动；
- RSSM 给所有候选链路相同的 logit correction，不能改变同一步内部各边的排序，只能整体移动阈值坐标；
- RSSM 给所有任务相同的状态修正，不能表达不同任务的随机阶段变化；
- 实体差异仍完全依赖 deterministic dual-graph base，RSSM 随机分支没有真正成为图结构的实体级动力学。

这与最新 v3 “correction 只改善 `23.79%` 节点”以及 node-x-safe “correction 几乎归零但 base 联合训练恶化”一致。该一致性是机制解释，不是因果证明或新方法性能证据。

## 对主线的启发与优先级

### 高优先级、可直接验证

1. **实体级可表达性审计。** 用已有 v3 checkpoint 计算 `target - base` 所需 correction 在节点、边和任务之间的离散程度，并与当前可表达的“同类实体共享一个 correction”作 oracle 对比。该审计不训练模型。
2. **运动信息充分性审计。** 按直行/转向拆分 h1/h5/h10/h20；确认现有历史是否能推断方向，以及 heading/速度向量/路线只作为历史合法信息还是未来控制条件。
3. **多任务梯度审计。** 测 node、link、task/operations 对 base、图编码器和 RSSM 的梯度夹角与幅度。

### 审计支持后才考虑的候选方法

候选名称暂定 `entity_aligned_dual_graph_rssm_v1`：

- 物理节点、物理/信息边、流和任务分别保留实体级 deterministic/stochastic state；
- 使用已有物理图、信息图和 CIP/CEP/CFL 做关系传播；
- 全局 pooled state 只负责真正的系统级上下文，不作为所有实体唯一的 correction 来源；
- 物理位置优先由合法运动状态和确定性更新产生 proposal，实体级 RSSM 只学习未解释残差和不确定性；
- 先训练/冻结可靠的实体编码与 deterministic base，再训练 prior/posterior，最后仅在固定门下决定是否小幅联合微调；
- 训练期使用自由 rollout、扰动输入或分阶段 horizon，减少训练输入与部署递推输入的分布差异。

这是一项“随机 latent 的粒度从 global aggregate 改为 entity-aligned”的候选架构变化，不得与 heading、loss、训练预算和事件建模同时改动。

## 当前判断

文献最强的启发不是换成 Transformer、JEPA、focal loss 或更大的 KL，而是先修正随机状态的结构粒度。当前完整 RSSM 语义实现可以作为对照和代码资产保留，但不应继续围绕广播 correction 调参。冻结 v3 base 再训同一个广播 correction 也不能解决表达能力问题，因此不再推荐为下一训练。

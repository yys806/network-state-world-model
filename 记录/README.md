# PI-JWM 记录

这里是项目后续更新的唯一记录入口。理论边界与证据规则维护在 `PIJWM主文档.md`，动态推进维护在 `8.12之后推进.md`，任务状态维护在 `本地计划表.md`。

- `研究进展/`：设计、实施计划、实验结果和审计报告。
- `接续记录/`：跨会话交接文档。
- `设计/`、`实施计划/`：已确认的方案与可执行计划。
- `工作日志/`：本地规划、发现和进度日志。
- `迁移/`：仓库结构迁移的映射、基线和验收证据。

历史材料中的旧路径仅作为 provenance 说明；现行命令和新记录使用根级 `code/`、`paper/`、`literature/`、`meeting/`、`docs/`。

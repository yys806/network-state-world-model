## 完成定义

P4 使用现有非 locked 验收门，不放宽 link、node-x、长步、运营、不确定性或一致性要求。短预算 `256/128/128` 只检查执行稳定性；正式性能使用全部 unlocked `9828/3276/1638` 窗口、固定 seeds `20260830/20260831/20260832` 和收敛训练。三 seed 通过后记录 `P4 non-locked accuracy gate=passed` 并开放 P6；`locked_test` 继续封存。

## 顺序

1. 建立统一 CPU 第一性原理审计：实体 residual 上界、link 排序限制、运动可观测性、共享梯度冲突、checkpoint 选择错位。
2. 用过去与当前位置以及 `slot_seconds` 因果派生速度/加速度，建立独立 unlocked motion tensor；不覆盖旧 tensor。
3. 新增 `entity_aligned_dual_graph_rssm_v1`：逐 node/physical-edge/flow/task deterministic/stochastic state，复用现有双图、规则层、完整 prior/posterior/KL/teacher/overshooting 语义。
4. 通过 TDD 和 canonical CPU micro 一致性门，冻结方法、tensor 和训练协议。
5. 用户开启 GPU 后先运行 2 epoch 执行 sentinel；其性能数值不作 No-Go。随后才允许完整 seed `20260831` 收敛训练，通过后再运行另外两个 seed。

## 固定方法与训练合同

- history/horizon=`8/20`，hidden=`32`，stochastic=`16`。
- AdamW，lr=`3e-4`，weight decay=`1e-5`，gradient clip=`5.0`。
- KL balance/weight=`0.8/0.1`，overshooting distance/weight=`5/0.1`，teacher reconstruction=`0.5`。
- 每个 seed 先完整训练 deterministic base，再冻结 base 训练 entity RSSM；失败的 node-x 非劣化 loss 不进入新方法。
- 最大 60 epoch，前 20 epoch不早停，之后 gate-aware 排名连续 10 epoch不改善才停止。
- checkpoint 按 `(失败硬门数, 最大归一化超限, validation state NLL)` 字典序选择。

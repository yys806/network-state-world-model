### Task 2：精确GRU重算与只读hook

- [ ] 在新脚本实现私有函数`_reconstruct_gru_cell(cell, input, hidden)`，严格使用PyTorch GRUCell的`r/z/n`权重分块：

```python
input_gates = F.linear(input, cell.weight_ih, cell.bias_ih)
hidden_gates = F.linear(hidden, cell.weight_hh, cell.bias_hh)
i_r, i_z, i_n = input_gates.chunk(3, dim=-1)
h_r, h_z, h_n = hidden_gates.chunk(3, dim=-1)
reset = torch.sigmoid(i_r + h_r)
update = torch.sigmoid(i_z + h_z)
candidate = torch.tanh(i_n + reset * h_n)
reconstructed = candidate + update * (hidden - candidate)
```

- [ ] 对float32和float64随机GRUCell测试`reconstructed`与真实output最大绝对误差不超过`1e-6`。
- [ ] 实现context manager `edge_gru_readonly_trace(model)`：只允许`model.edge_transition`为`GRUCell`；forward hook复制input、hidden、真实output、update gate和重算误差；hook返回`None`，不得替换output；finally移除。
- [ ] 测试hook前后正式output逐元素相同、只命中edge transition、异常退出也移除、退出后再次forward没有新增记录。

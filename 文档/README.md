# PI-JWM 文档索引

本目录保存研究设计、阶段证据、组会材料和本地文献。PI-JWM是研究框架；AirFogSim只作为参考仿真器和数据来源。

- 根目录`AGENTS.md`：永久仓库、理论和证据规则。
- 根目录`新对话接续说明_20260815.md`：当前接续说明；迁移后的复核修正以后续治理记录为准。
- 根目录`本地计划表.md`：唯一的本地执行总览。
- `知识库/PIJWM主文档.md`：固定理论、问题定义、方法、数据与实验规范。
- `知识库/8.12之后推进.md`：2026-08-12之后的实现进展、证据和阻断记录。
- `研究进展/2026-08-12-PI-JWM-v4信息边均衡协议设计.md`：当前信息边最小可靠集边界。
- `研究进展/2026-08-13-PI-JWM-P1-A-CPU动作边界冻结设计.md`：当前核心动作与CPU内层规则边界。
- `研究进展/2026-08-14-PI-JWM-P2-C正式数据规模与分布审计.md`：P2-C v1审计背景；v2最终状态还需结合最新handoff和机器artifact。

机器验收状态必须回到`代码/artifacts/`中的JSON、CSV和manifest核验，不能只凭叙述文档判断。

## 目录职责

- `研究进展/`：当前设计、实施计划、结果说明和历史研究记录。8月12日以前的世界模型、selector和旧数据协议材料默认属于历史证据，除非最新计划明确复用。
- `知识库/`：从原外部知识库迁入的两份权威工作文档；今后只维护仓库内版本，不再写回旧目录。
- `研究进展/归档/`：已退出当前主线但仍需追溯的旧版主文档、方法设计、工具和模板。
- `组会/`：本地组会PPT、讲稿、问答和归档。长PPT可能是多次汇报拼接文件，不能默认整份都是当前口径。
- `文献/`：本地论文附件和历史下载；Zotero是PI-JWM的权威文献库，新增前按DOI、arXiv ID、标题作者年份去重。

## 当前与历史边界

- 当前v4 E1是五个可核验字段，不补造旧18槽中无观测的13维。
- 当前核心动作是卸载加RB sparse COO；CPU是逐候选、逐rollout步的确定性内层规则。
- 旧R3-R6模型和策略结果是旧协议下的候选或历史工程证据。
- 当前R6没有逐候选调用世界模型预测未来状态、任务、成本和风险，不能称为candidate-rollout planner。
- 正式v4数据、新协议模型、规划器和最终方法均未完成。

## 写作与归档规则

1. 新设计和结果写入`研究进展/`，文件名使用`YYYY-MM-DD-PI-JWM-主题.md`。
2. 可执行实现放在`代码/src/pi_jwm/`，入口放在`代码/scripts/`，测试放在`代码/tests/`。
3. 生成数据、报告、图和checkpoint放在`代码/artifacts/`，不要放入文档目录。
4. 历史材料保留原始口径并明确标注，不通过改名把旧实现包装成当前方法。
5. 更新阶段状态时同步`本地计划表.md`，但不把大段实验日志继续堆入总览。

# PI-JWM 实验结果口径

## 统一结果类别

### deployable

测试时不读取真实未来动作或标签；模型、阈值、候选选择器和校准器不使用 test 拟合；最终配置由 train/val 确定后在 test 上评价。

### true_future_reference

包含以下任一情况：

- 使用完整真实未来动作。
- 使用真实第一步未来动作再预测后续步骤。
- 使用真实活动位置或真实动作幅值。
- 使用 `oracle_topk` 等真实预算信息。

该类别用于评价世界模型能力或定位策略误差，不是自主结果。

### sample_oracle

对每个样本事后选择误差最小候选。它只证明候选集合的上限，不代表存在可部署选择器。

### test_best_diagnostic

根据 test 表现事后选择候选、阈值或 checkpoint，或者在同一 validation 数据上同时拟合复杂 selector 并选择 operating point。该类别可用于定位 headroom 和过拟合，但不能作为最终对比。

## 必报字段

- framework、candidate、result_kind。
- 数据集和 train/val/test seed。
- fit_splits、selection_split、evaluation_split。
- 样本数和 active link-step 数。
- active-rate RMSE。
- activity precision、recall、F1。
- full-link、node、task RMSE。
- 命令、seed、checkpoint 和输出路径。

## 晋级规则

候选只有在 validation 规则预先固定、matched test 可复现、关键辅助指标没有明显崩溃时才能晋级。小切片、test-best、oracle 或真实动作结果不能单独触发大规模训练或版本升级。

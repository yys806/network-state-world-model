# PI-JWM R4 GPU模块筛选结果

日期：2026-08-04

## 1. 本阶段回答的问题

R4不是训练最终PI-JWM，而是在R1数据协议、R2评价协议和R3统一模型接口不变的条件下，一次只替换一个模块，判断哪些结构值得进入R5多seed组合复验。AirFogSim仅提供已冻结的轨迹数据；训练对象是PI-JWM世界模型。

固定实验口径为：训练seed `20260803`，有效batch size 32，最多30 epoch，patience 5；所有候选使用相同训练窗口和优化口径。checkpoint只由12条validation轨迹在1/5/20步共36个窗口上的综合分数选择。该分数等权汇总信息边活动`1-AUPRC`、活动信息边速率归一化MAE、任务生命周期`1-macro-F1`和十项连续状态归一化误差，数值越低越好。calibration和locked-test均未用于本轮选模。

Graph-RSSM相对参考臂使综合分数降低`0.7128%`，因此进入R5作为首选动力学候选。无跨图耦合臂差于参考臂，说明本轮数据支持继续保留跨图信息交换；但这不能证明当前门控耦合就是最优实现。异方差、DAG传播和预测presence没有在单模块综合分数上获胜，但分别对应不确定性、任务依赖和动态拓扑问题，仍可作为R5有限组合中的诊断模块。

必须同时保留负面结果：Graph-RSSM的信息边活动AUPRC仅`0.0015843`，任务生命周期macro-F1仅`0.0147243`。因此R4只能说明“训练和统一评价链路已跑通，并筛出优先复验候选”，不能说明世界模型已经收敛、预测效果已经可用或PI-JWM已经优于论文baseline。

## 3. 正确性与产物

正式第二轮共12/12候选成功、0失败，总耗时`3567.6608 s`。第一轮发现并修复两项实现问题：检查点复现容差过严；活动链路可能因中断出现零实现速率。修复后从零重跑全部候选，没有拼接两轮结果。

本地产物位于`代码/artifacts/formal_training/pi_jwm_r4_gpu_screening_v1/`。46/46个清单文件的大小和SHA-256在服务器与本地独立复算一致；12个最佳checkpoint均通过哈希和分数复现约束，`locked_test_accessed=false`。定向测试结果为R3 22/22、R4 49/49通过。

## 4. R5入口

R5不机械叠加所有单项模块。首先保留Graph-RSSM和参考Graph-GRU作为核心对照，再按研究问题有限加入异方差头、显式DAG消息和soft presence组合；每个正式组合至少使用3个训练seed，并继续使用相同数据、预算和R2指标。只有多seed下多步状态、链路、任务、动作敏感性、守恒和校准结果稳定，才能冻结正式世界模型并进入R6策略器比较。

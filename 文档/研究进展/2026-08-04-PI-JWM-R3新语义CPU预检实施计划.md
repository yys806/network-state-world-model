# PI-JWM R3新语义CPU预检实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改R1/R2冻结协议、不访问locked-test的前提下，构建并验证PI-JWM v3显式状态＋latent belief的1/5/20步CPU参考流水线。

**Architecture:** 新增只读R3动态窗口层，把R1完整轨迹转换为统一显式状态批次；新增模块化v3参考世界模型，分别编码物理图和信息图，经`CIP/CEP/CFL`门控耦合后进行动作条件latent递归并输出未来显式状态；新增masked loss、严格checkpoint和CPU产物构建器。旧`directed_dynamic_v2_1`只复用有向聚合、训练循环和工程校验思想，不复用旧节点/边语义。

**Tech Stack:** Python 3、PyTorch、NumPy、标准库JSON/CSV/hashlib、`unittest`、R1 `PIJWM-DG-Contract-v3`、R2 `PIJWM-Evaluation-Bundle-v3`。

```python
R3_MODEL_SCHEMA = "PIJWM-R3-Reference-World-Model-v1"

@dataclass(frozen=True)
class R3ReferenceConfig:
    hidden_dim: int = 16
    history_steps: int = 8
    use_cross_graph_coupling: bool = True

@dataclass
class BeliefSequence:
    physical_latent: torch.Tensor
    information_latent: torch.Tensor
    business_latent: torch.Tensor
    joint_latent: torch.Tensor

@dataclass
class R3RolloutOutput:
    predicted_explicit: dict[str, torch.Tensor]
    predicted_logits: dict[str, torch.Tensor]
    predicted_belief: BeliefSequence

class R3ReferenceWorldModel(nn.Module):
    def infer_belief(self, batch: ExplicitStateBatch) -> BeliefSequence: ...
    def rollout(self, belief, future_action, *, rollout_steps: int) -> R3RolloutOutput: ...
    def forward(self, batch, *, rollout_steps: int) -> R3RolloutOutput: ...
```

物理图与信息图使用不同参数，关系聚合复用`directed_relation_messages`和`weighted_index_mean`。`CIP`在设备—代理间传递，`CEP`在对应物理边—信息边间传递，`CFL`在数据流—实际承载信息边间传递；无耦合控制关闭三个跨图门，但保留相同输入输出schema。

## 计划自检结论

- 设计中的输入、双状态、耦合、动作递归、loss、checkpoint、R2接入、产物和失败边界均有对应任务。
- 所有新增生产接口都先有明确RED测试，再做最小GREEN实现。
- R1三步默认窗口与R3 1/5/20步要求通过只读动态视图解耦，不修改冻结数据。
- R3不实现R4候选占位算法，不把CPU数值当作方法选择证据。

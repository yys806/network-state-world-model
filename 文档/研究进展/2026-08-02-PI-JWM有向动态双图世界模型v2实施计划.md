# PI-JWM有向动态双图世界模型v2实施计划

> **执行要求：** 本计划在当前会话内按TDD逐项执行；每项先看到新增测试因缺少功能而失败，再写最小实现并运行v1/v2回归。

**目标：** 在不修改v1语义和当前GPU训练的前提下，实现有向消息传递、独立信息代理历史表示、动态实体/承载关系和可公平比较的v2训练入口。

**架构：** 新增`formal_directed_graph_ops_v2.py`和`formal_dual_graph_world_model_v2.py`，复用v1的数据窗口、概率输出头、损失和指标接口。v2使用软实体权重递归更新未来图关系，首轮仅支持AirFogSim正式数据中的直接有向承载；完整RSSM留作后续独立模型版本。

**技术栈：** Python 3、PyTorch、NumPy、unittest、AirFogSim正式非锁定张量。

- [ ] **步骤1：编写动态关系失败测试**

```python
cfe_next == direct_candidate * flow_weight_next.unsqueeze(-1) * edge_weight_next.unsqueeze(1)
```

- [ ] **步骤3：实现逐步动态更新**

第一步使用历史末时隙真实权重和`flow_bearer_mask`；每步输出后，以对应presence logits的sigmoid更新下一步实体权重，并用直接有向候选矩阵重算软`CFE`。任务和DAG权重按同样方式递归更新。输出增加`rollout_edge_weight`、`rollout_flow_weight`和`rollout_cfe_weight`，用于审计而不进入损失。

# PI-JWM R5 GPU正式训练实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 实现可恢复、可审计且不访问locked-test的R5 A-E三seed正式GPU训练，并完成远端运行与结果回传。

**Architecture:** 新建专用R5 GPU runner，复用R4的冻结窗口、批处理和指标累积器，使用R5组合工厂与严格checkpoint。15个run串行执行、逐epoch保存恢复状态、validation选模、calibration独立评价，汇总不自动指定winner。

**Tech Stack:** Python 3、PyTorch/CUDA、NumPy、JSON/SHA-256、Paramiko SSH/SFTP。

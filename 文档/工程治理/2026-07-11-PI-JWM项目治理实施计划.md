# PI-JWM 项目治理实施计划

> **执行要求：** 采用当前会话内联执行；每个代码修改任务遵循测试先行，清理任务遵循“清单 -> 隔离 -> 核验”，隔离区未经用户确认不得永久删除。

**目标：** 修复 PI-JWM 项目的结构、依赖、文档和高风险代码边界，隔离冗余内容，并保留一条可复现、可测试、可继续研究的主线。

**架构：** 保持 `代码/src/pi_jwm` 为可复用实现、`代码/scripts` 为命令入口、`代码/tests` 为验证、`代码/reference` 为第三方代码、`代码/artifacts` 为研究证据。第一轮不强制移动所有历史实验，而是通过保留索引、隔离清单和兼容入口逐步收敛。

**技术栈：** Python 3.11-3.13、PyTorch、NumPy、scikit-learn、unittest、PowerShell、Git。

# PI-JWM 项目治理结果

日期：2026-07-11

## 结论

本轮治理已将项目主线统一为 PI-JWM，并完成代码边界加固、项目入口重建、文档目录收敛、可恢复清理和实验证据索引。AirFogSim 继续作为参考仿真器与数据来源；当前决策方法仍是 `v11 candidate`，不是最终 v11 或 v12。

本轮只证明工程接口、数据边界和结果口径可执行、可验证，不证明模型性能因重构而提升。

## 代码与研究逻辑修复

1. 扩展 seed 数据集不再静默使用旧 0-9 seed 切分；train/val/test 必须显式给出且非空。
2. 训练 preflight 新增 action/target 的 ndim、history、horizon、edge 和 node 对齐校验。
3. selector aggregate RMSE 对 `active_count=0` 样本统一从分子和分母排除。
4. 双图测试验证端点索引会改变消息聚合，所有 future-action 步都会影响多步 rollout。
5. 新增 `pi_jwm.evaluation.result_protocol`，区分 `deployable`、`true_future_reference`、`sample_oracle` 和 `test_best_diagnostic`。
6. selector 的候选混合、SSE/RMSE 和 validation-selected matched-test 逻辑下沉到可测试模块。
7. 隔离工具新增多文件批量迁移，移动前完成根路径/目标冲突预检，移动后逐文件校验大小和 SHA256。

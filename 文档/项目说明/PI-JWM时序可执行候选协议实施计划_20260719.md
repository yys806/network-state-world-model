# PI-JWM Temporally Executable Candidate Protocol Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace stale task-ID delayed interventions with audited causal policy intents and reach a five-seed pre-training gate plus PPT-ready evidence.

**Architecture:** Keep reusable intent validation and pure resource projection in `pi_jwm`; keep AirFogSim state access in the diagnostic runner. Preserve the legacy task-ID path for historical reproduction, while formal selector-timed runs emit only `causal_policy_v1` candidates.

**Tech Stack:** Python 3.10+, NumPy, pandas, AirFogSim reference simulator, `unittest`, Matplotlib.

# PI-JWM Physical Benefit Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a leakage-safe, seed-crossfit bridge that converts aligned AirFogSim task/energy outcomes into test-time observable physical-benefit predictions for v11 selector features and conservative Pareto filtering.

**Architecture:** Keep AirFogSim execution in scripts and reusable alignment/model logic in `pi_jwm`. Generate selector-timed physical interventions, pair every candidate with its default, fit separate task and energy ensembles using five seed folds, calibrate intervals on seeds 44--49, and augment immutable `CandidateBatch` objects without populating actual-outcome fields.

**Tech Stack:** Python 3.10+, NumPy, scikit-learn, pandas in runnable scripts, `unittest`, existing PI-JWM schema-v6 caches, AirFogSim reference simulator.

```python
SUPPORTED_PHYSICAL_FAMILIES = {
    "default": "identity_control",
    "rb_count": "rb_repair",
    "mixed_offload_rb": "offload_rb",
    "cpu_scale": "compute_cpu",
    "return_route": "return_route",
}

def normalize_physical_family(name: str) -> str | None:
    return SUPPORTED_PHYSICAL_FAMILIES.get(str(name).strip().lower())

def align_decision_points(points, sample_index_rows, tolerance: float = 1e-8):
    by_key = {
        (int(row["seed"]), round(float(row["input_end_time"]), 8)): int(row["sample_id"])
        for row in sample_index_rows
    }
    aligned, rejected = [], []
    for source in points:
        row = dict(source)
        key = (int(row["seed"]), round(float(row["decision_time"]), 8))
        sample_id = by_key.get(key)
        if sample_id is None:
            rejected.append({**row, "reason": "no_exact_input_end_time"})
        else:
            aligned.append({**row, "sample_id": sample_id})
    return aligned, rejected
```

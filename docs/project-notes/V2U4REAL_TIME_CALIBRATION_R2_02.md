## 3. 数值字段：结构与解释分开

`metadata_field_audit.json` 保存全部 32 份 YAML 的位姿、相机矩阵数值/形状/类型、首个标注示例和诊断；`r1_strict_data_audit.json` 保存 PCD 头、XYZ 范围、字段类型和读取结果。只检查数值结构，不以结构通过宣称空间对齐正确。

| 实际字段 | 数据结构 | 已确认的消费语义 | 未确认内容 |
|---|---|---|---|
| `lidar_pose` | list[6]，元素 float，有限 | `basedataset.reform_param` 将其送入 `x1_to_x2`；`x_to_world` 按 x,y,z,roll,yaw,pitch 读取，默认角度为度，ZYX 组合 | 样本世界原点/地理参考、物理参考点、预定义轴变换及 GICP 修正是否已包含 |
| `ego_speed` | float，有限 | 官方称速度 | 此字段的原始单位未明；不用于回放 |
| `camera*.extrinsic` | 4×4 数值 list；车辆 3 组、UAV 1 组；底行为 0,0,0,1 | 名称及官方描述支持“相机外参” | LiDAR→camera 还是 camera→LiDAR，是否已含轴转换；不能当 LiDAR→机体或跨端注册矩阵 |
| `camera*.intrinsic` | 3×3 数值 list，有限 | 官方描述为相机内参 | 不能替代传感器外参或配准矩阵 |
| `vehicles.*.location/center/extent/angle` | 各 list[3]，有限；extent 全正；本段 center 全为 [0,0,0] | 转换脚本将 location 当 x,y,z、extent 当 dx,dy,dz、angle[1] 当度制 yaw；`create_bbx` 对三轴全尺寸各除以 2 | 本段 center 为零不能证明普遍恒零；论文 l,w,h / roll,pitch,yaw 文本顺序与代码消费顺序应分开 |
| `vehicles.*.obj_type/speed` | str / float；每帧车辆标签 5–6、UAV 标签 1–2 | 同 stem YAML 是官方读取器的标注来源 | 跨端同 ID 的实际对象一致性、物理时刻关联未验收 |

## 4. 标定缺口及源码分支

完整包内只有传感器 PCD 和对应 YAML，未见独立时间表、LiDAR→机体外参文件或跨端注册矩阵文件。样本 YAML 没有 `transformation_matrix`、`gt_transformation_matrix` 或 `spatial_correction_matrix` 原始字段；官方 `basedataset.py:485–522` 根据位姿在运行时计算并写入这些字段。因此“原始字段不存在”不等于官方管线没有跨端计算能力，也不能把运行时生成矩阵说成实测标定矩阵。

R1/R2-01 已发现的分支保持原样：list+list 为第二位姿逆矩阵乘第一位姿；list+matrix 直接将第二矩阵左乘第一位姿矩阵。真实融合调用传直接 LiDAR→ego 的矩阵，仿真分支传 ego_pose 列表；通用 docstring 仍未覆盖混合分支契约。`vehicle_to_single.py:62–85` 使用 location；`uav_to_single.py:65–113` 使用 location+center。本段 center 都为零，无法用这些样本区分两种处理；本轮不构造真实变换或替研究者选分支。

## 5. 重复内容及解除条件

不同发布 key 下车辆 PCD 完全相同的两组：`1752814590.7/.8` 与 `1752814590.9/1752814591.0`，SHA 和路径见 `sample_manifest.json` 的 `duplicate_payload_groups`。对应 YAML 的 SHA 不同；UAV 的 16 份 PCD 无字节重复。原始文件从通过整包 SHA 的内容提取，重名成员为 0，所以这不是提取器覆盖同一文件造成的证据；采集、重采样或发布流程中的原因未知。

解除物理验收阻塞至少需要：

1. 官方已有资料中的逐端原始时刻/时钟映射、单位、原点与配对误差证据，并解释上述重复文件的来源。
2. 将样本 `lidar_pose`、PCD 轴、注册修正及相机外参方向明确绑定的标定说明；明确机体/天线偏置是否提供。若确实未提供，后续边界需由研究者确定。
3. 下一任务另行授权后，再做真实坐标正逆变换与点云/标注叠加验收；当前为 NOT_RUN。

本轮没有确定虚拟 RSU 位置。其公共系/原点/轴/单位、位置/姿态、机体或天线偏置与时间映射仍需独立配置，数值只可作为仿真实验设定。

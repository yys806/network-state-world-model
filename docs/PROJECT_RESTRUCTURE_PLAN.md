# PI-JWM 项目重构实施计划

## 目标

建立一套让用户逐步重新掌握科研内容、让 AI 能够快速检索和长期维护的项目知识结构；不改变研究问题、算法原理、模型、loss、指标、实验目的或已有结论。

## 已确认约束

- 当前远端 GPU 正式训练已结束，正式产物已回传；同步相关目录仍按保护对象处理，未确认静止前不做结构迁移。
- `code/artifacts/` 中的训练、同步、checkpoint、tensor、manifest、协议和原始结果是保护对象。
- 归档优先于删除；历史失败实验和旧配置必须可追踪。
- 索引用于导航，原始代码、配置、日志、metrics、checkpoint 和 audit 用于验证。
- 当前 P4 未关闭，P6 未开放，`locked_test` 封存。
- 本轮不重复执行 2026-08-16 已完成的顶层目录迁移，不移动 RRM，也不恢复已删除的旧资料。
- 2026-09-09 用户明确调整优先级：seed `20260832`、远端训练和远端同步延后，先完成项目重构；现有训练接口只做登记和守卫，不自动启动。

## 阶段 1：安全导航层（已完成）

只新增或小范围补充导航文档：

- 项目地图：`docs/PROJECT_INDEX.md`；
- 架构说明：`docs/ARCHITECTURE.md`；
- 当前科研状态：`docs/RESEARCH_STATUS.md`；
- 实验索引：`docs/EXPERIMENT_INDEX.md`；
- 结果索引：`docs/RESULTS_INDEX.md`；
- 结构变更记录：`docs/CHANGELOG.md`；
- 本实施计划：本文件。

阶段 1 不移动、不重命名、不删除任何已有文件，不写入当前训练证据目录。

## 阶段 2：只读证据映射（已完成）

在确认同步静止后，生成可审计的文件/实验映射：

- 当前代码入口、测试覆盖和脚本入口；
- 实验 ID、研究问题、配置、数据、checkpoint、结果和 audit；
- 历史方法、失败原因和替代关系；
- 文档之间的权威关系和冲突清单。

这一步仍不移动原始 artifact；映射必须包含路径、状态和必要的 SHA-256。

当前产物位于 `docs/registries/`：覆盖项目文件、Python 依赖和反向引用、artifact 一级目录、重要实验/结果、文档权威关系、延后任务和归档候选。自动目录不哈希 checkpoint 或 predictions，只读取目录元数据和小型控制文件。

## 阶段 3：受控归档和去重（逻辑归档完成，物理迁移停止）

只有满足以下条件后才讨论移动或归档：

1. 远端训练结束，正式目录已发布；
2. 同步过程静止，相关文件不再变化；
3. 用户确认迁移范围；
4. 生成逐文件映射、哈希、冲突检查和回滚脚本；
5. 分批迁移，每批完成后验证路径、引用、测试发现和 evidence manifest。

任何删除都必须先有明确的科研价值判断、归档副本和可恢复记录。

当前 211 个历史 Python 节点已逐文件登记；94 个仍有反向引用、93 个仍有直接测试。虽然当前正式节点没有引用它们，但全量测试基线仍受环境、fixture 和历史 artifact 权限问题影响，无法可靠区分物理迁移引入的回归。因此本轮保持原路径，只通过生命周期标签实现逻辑隔离；没有移动或删除。

## 阶段 4：持续维护（机制已建立）

以后新增算法、实验、结果、配置、路径或结论时，同步更新相应索引；涉及理论边界或正式性能时，还必须更新现有 `记录/` 权威文件。重要改动完成后检查代码、实验、结果、文档和索引是否一致。

## 阶段 5：长期协作与问答闭环（已完成）

本阶段以“用户提问后能够先快速找到正确入口，再回到原始证据核实”为验收目标，且继续保持无损边界：

1. 将用户与 AI 的职责、独立质疑义务、通俗解释顺序和反空泛要求写入永久治理规则；
2. 统一重要实验的必填字段；不适用或未知的字段必须显式为 `null` 并写明原因，不能省略或猜测；
3. 建立重要历史方法注册表，记录为什么尝试、实际结果、为什么不再是当前方法、替代关系和原始证据；
4. 对正式结果注册表中的指标、epoch、seed、状态和 `locked_test` 边界执行原始 acceptance JSON 自动复核；
5. 提供面向常见自然语言问题的只读检索入口，并测试当前方法、历史失败、正式结果和延后任务四类问题；
6. 将上述检查接入统一 `--check`，重要信息变化后必须同步维护。

本阶段不移动历史文件，不修改研究方法、模型、loss、指标、阈值、协议或实验产物，也不启动 GPU、第三 seed 或远端同步。

完成证据：统一生成器和 `--check` 通过；项目知识/结构测试 27/27、正式 P4 测试 210/210 通过；全量 1636 项为 0 failure/21 个已登记环境或历史错误。自然语言问题、精确旧实验目录和精确代码文件名均已纳入自动查询测试。

## 回滚原则

- 第一阶段索引文件可单独删除或回退，不影响训练和原始证据。
- 未来迁移必须依据本轮映射逐文件反向恢复，不使用宽泛递归删除。
- 若验证发现 layout-induced 证据错误，立即停止后续迁移，保留失败现场并报告。

# robustness_v0 阶段小结

## 任务设置

- 训练：clean `dataset_v0`
- 测试：在输入侧加入合成扰动，标签保持原始未来状态
- 扰动强度：0.00、0.05、0.10、0.20、0.30
- 扰动类型：
  - 节点侧：位置、速度、加速度加高斯噪声
  - 链路侧：距离加性噪声，速率和 CSI 乘性噪声，任务/RB 占用加性噪声
  - 任务侧：聚合任务特征按标准差加高斯扰动并截断为非负

## 北大汇报口径评估

这一项已经完成“构造扰动测试数据”和第一版“抗扰动 baseline 实验”。结果可以用于回答老师关于扰动和随机性的问题，但目前仍是合成扰动实验，不是 AirFogSim 内生随机性完全建模。

当前结论是：随着扰动强度增加，任务状态预测误差明显上升，说明任务聚合状态对输入扰动比较敏感；链路速率上，persistence 由于主要延续最后观测，对输入扰动不敏感，而 Ridge residual 会随噪声增大明显退化。这说明当前学习式 residual baseline 的鲁棒性还不够，需要后续加入扰动训练、更强正则或更稳的双图模型。

汇报时不能说“我们方法抗干扰更强”，应该说：已经建立扰动评估流程，第一版结果显示当前 baseline 在强扰动下会退化，后续会通过扰动训练和结构化建模提升鲁棒性。
